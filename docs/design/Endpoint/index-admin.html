Admin endpoint specification. Corresponds to the Admin Endpoint definition in docs/architecture/components.md.

Authentication

Auth routes (sign-in / sign-out / OAuth callbacks) are provided by the Auth adapter at app/api/auth/[...auth] (framework-managed via providers.auth.handlers delegation). The concrete URL scheme is adapter-defined and is not specified in this document.

Business endpoints assume an authenticated principal via getPrincipal() and do not own sign-in or sign-out flows. role=admin is enforced per-route via requireAdmin() — not by individual endpoint sign-in logic.

CSRF protection relies on the SameSite cookie policy (Auth.js-independent); no X-CSRF-Token header is required.

All /api/admin/** paths require role=admin enforced per-route via requireAdmin(). Operations touch ACCOUNT / SCENARIO / PERSONA / RESULT / SETTING via the Store. Player endpoints (/api/player/**) are documented in ./openapi.yaml.

Auth

Account registration and credential management (via providers.auth)

Register a new account

Delegates to providers.auth.register().

  1. Accept RegisterRequest (email / credential / username?)
  2. Call providers.auth.register() — validates input, checks for duplicate email, and persists the new account
  3. Return the created AccountProfile with 201

Not admin-only: used for self-registration (players) and admin-initiated account creation when the Auth.js adapter is active.

Change the authenticated user's credential

Delegates to providers.auth.changePassword().

  1. Verify session via SessionCookie (401 if unauthenticated)
  2. Accept CredentialChangeRequest (currentCredential / newCredential)
  3. Call providers.auth.changePassword() — verifies currentCredential (401 if mismatch), validates newCredential (min 8 characters), and persists it
  4. Return 200

Get per-scenario grade summary across all users

  1. Verify session via SessionCookie (401 if unauthenticated)
  2. Verify role=admin (403 if not admin)
  3. Call Store.scenarios.get(id) (404 if not found)
  4. Call Store.results.listRecent() and filter to this scenario's RESULTs, then join with Store.accounts.list() for email/username
  5. Parse each RESULT's evaluation JSON to extract its score
  6. Group by accountId (results with no accountId are grouped as one anonymous bucket) and aggregate play count / average score / best score per user
  7. Return AdminScenarioResultsSummary with 200
  • Anonymous plays (accountId null) are aggregated into a single entry with accountId/email/username all null.

Delete a single system setting

  1. Verify session via SessionCookie (401 if unauthenticated)
  2. Verify role=admin (403 if not admin)
  3. Call Store.settings.get(key) (404 "not_found" if the key does not exist)
  4. Call Store.settings.delete(key)
  5. Return 204 (no content)
