Studyme team members: maintain notes under `docs.local/`:

| Path | Purpose |
|------|---------|
| `docs.local/TEAM.md` | チームオンボーディング（セキュリティ・hooks・運用） |
| `docs.local/re00/HANDOVER.md` | **Providers/Adapters 基盤開発の引き継ぎ（開発開始はここ）** |
| `docs.local/re00/providers.html` | Provider 設計の HTML 資料（任意） |

開発ブランチ: `re00-dev`

Create `docs.local/` on first clone if missing (copy from a teammate or internal backup).
Public security setup: `SECURITY-SETUP.md` at the repository root.
